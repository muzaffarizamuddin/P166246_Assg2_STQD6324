## Abstract

This repository demonstrates a distributed data pipeline for movie preference analytics, using the MovieLens 100K dataset as a foundational case study. Single-node architectures struggle under the heavy real-time data input and memory demands generated by modern streaming applications. To mitigate this, the project uses a potentially scalable architecture leveraging **Apache Hadoop HDFS** for fault-tolerant distributed storage, **Apache Spark (PySpark)** for parallelized in-memory computations, and **Apache Cassandra** for low-latency scalable query execution via CQL. 

Raw computational processing is executed on Hortonworks Data Platform (HDP 2.6) cluster using detached `spark-submit` jobs split into modular routines: average rating (`average_rating.py`) and user profiling (`users_analysis.py`) was split into seperate scripts. Analytical outputs are dynamically synchronized from Cassandra back into structured CSV for visualization in python.
